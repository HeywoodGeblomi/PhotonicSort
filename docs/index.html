PhotonicSort

Adaptive hybrid sorting library — C11 core + Python reference · MIT · v1.0.1

PhotonicSort is a classical adaptive sorting algorithm. A single-pass disorder probe chooses between structure-aware early exits and a stable residual sort. The production implementation is a C11 library (libc only). A pure-stdlib Python module serves as a reference and research harness.

This is not optical hardware, not a claim of light-speed sorting, and not a P = NP result. Worst-case complexity remains O(n log n).

Algorithm sketch

  1. Probe — one O(n) (or stratified-sample) pass: inversion ratio, max run, run count, direction changes, sortedness.
  2. Structure early-exit — sorted → no-op; reverse → in-place reverse; other high-structure cases may take a near-linear path.
  3. Residual sort — stable bottom-up mergesort (C) when an early exit is not authorized.

C11 usage

#include "photonic_sort.h"

int64_t a[] = {7, 2, 9, 1, 5, 3, 8, 4, 6, 0};
photonic_sort_i64(a, 10);   /* in-place adaptive */
cd c && make && make test
make release    # -O3 -DNDEBUG -flto
make static     # fully static (scratch / distroless)

Architecture note

The C library is a standalone C11 translation unit, not a Python C-extension. It does not touch the Python GIL. The Python package is a separate pure-stdlib reference.
